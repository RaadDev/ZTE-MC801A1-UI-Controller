# 📡 موجّه - Mowajjih (ZTE MC801A & MC801A1 Manager)

تطبيق سطح مكتب احترافي عالي الأداء باللغة العربية مخصص لمراقبة وإدارة وبرمجة راوترات **ZTE MC801A** و **ZTE MC801A1 5G** على نظام التشغيل Windows. يعمل التطبيق عبر واجهة مستخدم عصرية فائقة السرعة بنظام الاتجاه من اليمين لليسار (RTL) مع جسر محلي آمن ومستقل (`LocalBridgeServer`).

## 🌟 الميزات والأقسام الرئيسية للتطبيق

تم تنظيم لوحة التحكم في **3 مجموعات ذكية** تضم **6 أقسام رئيسية متكاملة**:

### 1. نظرة عامة وتفاصيل الإشارة (Overview & Signal Details)
- **مؤشرات لحظية حية:** عرض فوري لنوع الشبكة (`5G NSA` / `5G SA` / `4G+ LTE`)، ومزود الخدمة (STC, Zain, Mobily, إلخ).
- **مؤشرات جودة التردد الدقيقة:**
  - **RSRP:** قوة الإشارة الواصلة بوحدة dBm مع مؤشرات لونية فورية.
  - **RSRQ:** جودة إشارة القناة بوحدة dB.
  - **SINR:** نسبة الإشارة إلى التشويش لبيان نقاء التردد.
- **تفاصيل الخلية والمودم:** رقم البرج والخلية الفيزيائية (`PCI`)، رقم القناة الترددية (`EARFCN`)، قنوات التجميع النشطة (`Carrier Aggregation`)، درجة حرارة المودم الداخلية، وإصدار الفيرموير.
- **المنبه الصوتي التوجيهي (Audio Beacon):** نغمات صوتية متغيرة النبرة لمساعدتك في توجيه الراوتر نحو أفضل نافذة أو زاوية للحصول على أقوى إشارة دون الحاجة للنظر للشاشة.
- **الوضعان النهاري والليلي (Dual Mode):** دعم كامل للتبديل الفوري بين الوضع الفاتح (Light Mode) والوضع الداكن (Dark Mode) بنقرة زر أو عبر اختصار لوحة الأوامر السريعة (`Ctrl+K`).

### 2. الأجهزة المتصلة (Connected Devices)
- جدول حي يكشف جميع الأجهزة المتصلة عبر شبكتي السلك (Ethernet) والواي فاي (Wi-Fi 2.4GHz & 5GHz).
- كشف تلقائي عن أسماء المصنّعين استناداً لقاعدة بيانات معرفات MAC (مثل Apple, Samsung, Huawei, Sony, Dell, إلخ).
- حماية الأجهزة بوضع القراءة الصارمة لضمان عدم انقطاع بث الراوتر.

### 3. اتصال الراوتر وشبكة Wi-Fi (Connection & Wi-Fi Settings)
- **إدارة بيانات الشريحة:** إمكانية فصل وتوصيل اتصال البيانات الخلوية (WAN Connect / Disconnect) بنقرة زر.
- **بيانات شبكة Wi-Fi:** استعراض اسم الشبكة وحالة البث، وتوليد كلمات مرور عشوائية فائقة الأمان.
- **رمز الاستجابة السريعة (Wi-Fi QR Code):** مسح الكود بكاميرا الهاتف للاتصال الفوري بالشبكة دون كتابة كلمة المرور يدوياً.
- **مؤشر وقت الاستجابة (Ping Latency):** فحص مباشر لزمن الاستجابة مع الراوتر للكشف عن أي بطء في الشبكة المحلية.

### 4. النطاقات وتثبيت الترددات (Bands & Cell Lock)
- **قفل نطاقات 5G NR:**
  - دعم كامل للنطاقات: `N78`, `N41`, `N77`, `N28`, `N1`, `N3`, `N20`.
  - معالجة ذكية لحساب الـ Bitmask وإرسال توقيعات المصادقة `AD Token` حتى مع فيرمويرات ZTE السعودية ومزودي الخدمة (`BD_SAUMC801AV1.0.0B07`).
  - دعم 7 استراتيجيات تعاقبية تضمن قبول الراوتر للأمر مهما اختلف إصدار نظامه.
- **قفل نطاقات 4G LTE:**
  - دعم كامل للنطاقات: `B1`, `B3`, `B7`, `B8`, `B20`, `B28`, `B38`, `B40`, `B41`, `B42`.
  - تطبيق صيغة `BAND_SELECT` الدقيقة مع أقنعة الـ Bitmask المتوافقة لفك وتثبيت الترددات.
- **تثبيت الخلية والبرج (Cell Lock):**
  - تثبيت الراوتر على برج محدد عبر إدخال `PCI` و `EARFCN` لمنع القفز المزعج بين الأبراج البعيدة في أوقات الذروة.
- **تحديد نمط الشبكة:** التحويل المباشر بين `تلقائي (5G / 4G)`، `الجيل الخامس فقط (5G Only)`، و `الجيل الرابع فقط (4G LTE Only)`.

### 5. الرسائل القصيرة (SMS)
- قراءة وتصفح رسائل SMS الواردة لشريحة الراوتر وقراءة أكواد التحقق (OTP) ورسائل الباقات دون الحاجة لفك الشريحة.
- إمكانية حذف الرسائل القديمة للحد من امتلاء ذاكرة الشريحة.

### 6. الإعدادات المتقدمة (Advanced Settings)
- **إدارة الطاقة والراحة:** جدولة وضع السكون وإيقاف/تشغيل بث Wi-Fi لتوفير الطاقة وتقليل الانبعاثات ليلاً.
- **الشبكة و DHCP:** نطاق عناوين IP، زمن حجز العنوان (Lease Time)، وتحسين قيم MTU و MSS الموصى بها لمنصات الألعاب.
- **الأمان وجدار الحماية:** تفعيل UPnP لمنصات الألعاب (PlayStation / Xbox)، ووضع DMZ للأجهزة ذات الأولوية.
- **الصيانة وإعادة التشغيل:** فحص التحديثات، جدولة إعادة التشغيل اليومية التلقائية، واستعادة ضبط المصنع الآمنة.

## 🔒 معايير الأمان والخصوصية الصارمة

1. **جسر محلي منعزل:** يعمل خادم الوساطة المحلي فقط على العنوان الداخلي `127.0.0.1` ولا يمكن الوصول إليه من أي جهاز خارجي على الشبكة.
2. **حماية صارمة ضد هجمات SSRF:** يُحظر تماماً إجراء أي طلب نحو عناوين الإنترنت الخارجية (Public IPs). الاتصال مسموح حصراً بالعناوين الخاصة الموثوقة (مثل `192.168.0.1` و `192.168.1.1`).
3. **انعدام تخزين كلمات المرور:** لا يقوم التطبيق بتسجيل أو حفظ كلمات مرور لوحة تحكم الراوتر على القرص الصلب نهائياً.
4. **تفريغ الذاكرة المؤقتة:** فور قطع الاتصال أو إغلاق التطبيق، يتم مسح رمز الجلسة (Session Stok) والتوقيعات بالكامل من الذاكرة الحية (RAM).

## 💻 دليل المطور وأوامر التشغيل والبناء

### المتطلبات الأساسية
- نظام تشغيل **Windows 10 / Windows 11**.
- بيئة **Node.js 20+** مثبتة على الجهاز.

### أوامر المشروع (NPM Scripts)

| الأمر | الوظيفة |
| :--- | :--- |
| `npm.cmd start` | بناء المشروع وتشغيل التطبيق في بيئة التطوير المباشرة. |
| `npm.cmd run build` | ترجمة وتجميع كافة ملفات TypeScript إلى مجلد `dist/` عبر esbuild. |
| `npm.cmd run pack` | بناء حزمة الإنتاج المضغوطة (Minified Production Build). |
| `npm.cmd run typecheck` | التحقق الصارم من أنواع TypeScript واكتشاف أي أخطاء برمجية (`tsc --noEmit`). |
| `npm.cmd test` | تشغيل الفحوصات الآلية للتحقق من أمان وصحة الجسر المحلي (`tests/test_bridge.js`). |
| `npm.cmd run dist` | **بناء حزم التثبيت والنسخة المحمولة بالكامل لنظام Windows في مجلد `release/`.** |
| `npm.cmd run dist:setup` | بناء مثبت الإعداد الرسمي فقط (`mowajjih-setup.exe`). |
| `npm.cmd run dist:portable` | بناء النسخة المحمولة فقط (`mowajjih-portable.exe`). |
